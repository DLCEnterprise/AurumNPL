Executive Summary

The 4-week institutional-grade sprint is complete.
Aurum is live and production-ready.

Aurum was built across 14 core development sprints, delivering a fully functional NPL marketplace — multi-role authentication, admin approval gates, NDA-gated document access, bid management, due diligence workflows, deal pipeline, real-time messaging, and a Google Maps–integrated listing browser. The domain logic was sound from the start.

A subsequent 4-week hardening sprint closed every critical security gap, eliminated a known-CVE dependency, self-hosted all fonts, wired a full CI/CD pipeline, added Sentry error monitoring, activated distributed Redis rate limiting, wrote the first test suite (41 tests), and elevated the visual language to institutional-grade marketplace. The platform is deployed and running at production quality as of May 2026.

Track C — Design Elevation

From Fintech Startup → Institutional Marketplace

Before (Inception)
Card surfaces used glassmorphism (backdrop-filter) — 2021–2022 consumer fintech language
Border radius 16–24px on cards — signals "friendly app," not institutional platform
Gold gradient applied to 15+ elements — accent diluted, no visual hierarchy
Section headings at font-weight 300–400 — editorial fashion, not financial authority
Glow box-shadows on buttons — web3/crypto visual language
No motion accessibility — animations play regardless of user preference
Financial numbers without tabular-nums — columns don't align
After (Delivered)
Hard opaque surfaces — defined edges, border-based depth. Bloomberg / ICE register.
Border radius 4–8px — authority and precision at every edge
Gold reserved for 3 moments: wordmark, primary CTA, one key metric per screen
All display headings at font-weight 600 — Cormorant Garamond becomes commanding
Directional shadows — tight, dark, no glow. Precision over decoration.
Universal prefers-reduced-motion — all animations suppressed for users who need it
tabular-nums on all financial data — tables align, credibility increases
Signature Elements Delivered
① Gold hairline rule
32×1px gold underline beneath every section header.
Costs 0KB. Reads as deliberate craft.
② Tabular financial numerics
font-variant-numeric: tabular-nums on all data values.
Numbers align. Credibility is in the details.
③ Keyboard-accessible messaging
Full ARIA roles, aria-pressed, aria-label, onKeyDown.
WCAG 2.1 AA compliant throughout.
