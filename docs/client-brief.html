Executive Summary

Aurum has a strong foundation.
Now we make it institutional-grade.

Aurum's platform was built in 14 focused development sprints, delivering a fully functional NPL marketplace with multi-role authentication, admin approval gates, NDA-signed document access, bid management, due diligence workflows, and a real-time messaging system. The domain logic is sound. The auth architecture is unusually mature.

The next phase closes a small number of high-leverage security gaps, reduces the first-load bundle by an estimated ~147KB, and elevates the visual language from "fintech startup" to institutional-grade marketplace — the register that serious counterparties expect before they sign an NDA.

Requires Immediate Action !
!
Admin approval tokens stored as plaintext JWT — DB breach exposes live approval links. Fix: SHA-256 hash before storage (same pattern as password reset).
!
User data in admin emails not HTML-escaped — malicious company name can inject HTML into admin inbox.
!
Rate limiting bypassed via IP spoofing — X-Forwarded-For taken at face value without validation.
!
Rate limiter fails open on Redis downtime — auth endpoints unprotected during outage.
!
XLSX package abandoned + CVEs — spreadsheet import uses unmaintained library with known vulnerabilities.
!
No CI/CD pipeline — every push to production has zero automated gates: no type-check, no lint, no security scan.
Track C — Design Elevation

From Fintech Startup → Institutional Marketplace

Current State
Card surfaces use glassmorphism (backdrop-filter) — 2021–2022 consumer fintech language
Border radius 16–24px on cards — signals "friendly app," not institutional platform
Gold gradient applied to 15+ elements — accent diluted, no visual hierarchy
Hero headline at font-weight 300 — editorial fashion, not financial authority
Glow box-shadows on buttons — web3/crypto visual language
Arbitrary 28 font sizes — no modular scale, hard to maintain
Logo letter-spacing 0.15em — too loose, feels casual
Financial numbers without tabular-nums — columns don't align
After Elevation
Hard opaque surfaces — defined edges, border-based depth. Bloomberg / ICE register.
Border radius 4–8px — authority and precision at every edge
Gold reserved for 3 moments: wordmark, primary CTA, one key metric per screen
Display headings at font-weight 600 — Cormorant Garamond becomes commanding
Directional shadows — tight, dark, no glow. Precision over decoration.
10-step Major Third type scale — consistent, maintainable, readable
Logo letter-spacing 0.06em — solid, confident wordmark
tabular-nums on all financial data — tables align, credibility increases
Signature Elements Added
① Gold hairline rule
32×1px gold underline below every section header.
Costs 0KB. Reads as deliberate craft.
② Tabular financial numerics
font-variant-numeric: tabular-nums on all data values.
Numbers align. Credibility is in the details.
③ Gold focus ring
2px gold outline, sharp corners, on keyboard focus.
Brand as accessibility. Already partially in place.
